# 우리집 AI 위키 가족 대시보드 (GitHub Pages + Gemini API)

이 압축 파일 안의 모든 파일(`index.html` 및 `.md` 문서 4개)을 GitHub 저장소에 그대로 업로드한 뒤 **Settings -> Pages**에서 Branch를 `main`으로 설정하면 우리 가족 전용 대시보드 웹사이트가 만들어집니다.

1. **Google AI Studio 무료 키 발급**: https://aistudio.google.com/docs/api-key 에서 `Create API key` 클릭
2. **거실 태블릿 접속**: 생성된 GitHub Pages 주소 접속 -> 우측 상단 `AI · GitHub 설정` 클릭 -> Gemini API 키 및 `아이디/저장소이름` 입력 후 저장
